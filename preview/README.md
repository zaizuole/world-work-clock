# 全球工作时钟：设计预览 v0.3

这是用于审阅布局和交互方向的独立 HTML 原型，属于**局部预览**，不是正式应用，也不是完整日历工具。

## 运行

在项目根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/preview/>。没有安装前端依赖、登录或真实用户数据。

## 可以体验

- 桌面按统一北京时间轴比较各国工作时段；手机将时间带移到国家行下方。
- 初始模拟时间为 2026-10-26 16:30（UTC+8），可拖动时间、选择日期及回到设备当前时间。
- 筛选工作中/假日影响，展开代表城市，调整本次页面关注地区。
- 切换节日日历及国家筛选。

## 预览限制

- 仅内置新西兰 2026-10-26 劳动节的工作状态样例，其余日期先按普通周一至周五计算。右侧与日历另含未来假日展示样例，不是完整日历；美国/俄罗斯的代表城市数量比正式设计精简。
- 时间带显示每国首个代表城市，国家状态汇总本次配置的代表城市；正式版详情应显示每个代表地区的完整时间带。
- 没有实际数据源加载、完整调休、缓存、数据覆盖状态、权重配置和本地持久化。关注选择刷新后恢复。
- “回到现在”只恢复当前时钟，不会让样例日历变为真实日历。工作城市数量只是演示计算，不能据此判断真实流量。
