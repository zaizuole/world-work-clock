# 技术和视觉方案

保留 React/Vite/TypeScript、Python holidays 0.107、同源静态 JSON 与现有模块。新增日历窗口覆盖摘要，分别报告缺失与预测地区/年份。强化 JSON 的对象、元数据、年度非空与国家归属校验；仍允许部分区域缺失并在使用时标为未知。工时内未知日历不能给出确定工作结论。

设置校验拒绝非对象与非有限权重总和；覆盖计算维持全部关注地区分母。请求失败通过函数式状态更新保留已加载的内存数据。模拟参数只接受合法日期和显式时区的 ISO instant。

视觉沿用 #F5F5F7 背景、#FFFFFF 内容、#1D1D1F 文字、#6E6E73 次级、#E4E4E7 分隔、#0066CC 操作色；绿/琥珀仅小面积状态。部分城市入口加一行紧凑时间范围，地区日历页增加轻量模式条与覆盖说明。保持系统中文字体、等宽时间数字，使用现有布局和间距，不增加同权重装饰卡片。

测试采用真实静态快照及明确拦截的故障样例；故障测试不能当作真实生产数据核验。真实部署截图从正常 Pages 地址拍摄，与旧版使用相同模拟 instant、视口和主题。
