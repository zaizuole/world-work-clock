# 完整交付复核：日历未知与模拟状态

复用现有应用与 Pages，不新建仓库。当前实现已有基础功能，本次补齐会影响结论可信度的边界。

## 需求与验收

1. 部分工作国家同时显示明确的部分城市状态及所选城市当地时间范围；手机首屏保留工作概览与假日。
2. 切换假日日历仍持续显示模拟日期及返回现在入口。模拟链接必须带时区，不受设备时区影响。
3. 14/90 天窗口逐地区检查覆盖。缺失年份/地区显示未知，预测年份明确标记，不能用空列表断言无假日。
4. 损坏/空日历不进入有效缓存；请求失败回退有效缓存或本页内存。非法设置与会溢出的权重不能产生 NaN。
5. 完成本地业务与浏览器验证、CI 测试及真实 Pages 桌面/手机验收后再记录已交付。
